# Home Hub Dashboard Design

## Purpose

The Home Hub dashboard is the main visual interface for the ShepByte Home Hub.

The design should feel clean, modern and interactive without becoming visually cluttered.

The dashboard should provide a quick overview of the Home Hub first, then allow the user to move into different branches such as Devices, System and Activity.

---

# Main Design Style

The dashboard should use:

- Minimal 3D design
- Dark background
- Clean layout
- Soft lighting and glow
- Low-poly visual elements
- Subtle animation
- Smooth transitions
- Simple readable text
- Limited visual clutter

The interface should not look like a busy fantasy scene or a traditional solar system.

The branches should feel more like connected data paths or cables extending from the central Home Hub node.

---

## Branches & Nodes

Think of like a spider chart (it's what they were called when I was at School)

Homehub is the main circle. It would then have branches or legs (I'm going to stick with branches).

Devices
System
Activity

These branch off in to Nodes. So Homehub is the main Node and it branches off to other Nodes. These Nodes can also have branches for example Device node will attached Devices.

Planter 1

AI Companion

## Node Appearance

Now I'm dreadful at creating graphics, (I even went to uni). But in this day and age we have AI.
The idea would be when a device is connected it will have some form of description. Which and AI would generate graphics for the nodes.

Smart Planter
Small low-poly planter with plants, water and subtle movement.

Weather Station
Cloud, wind or weather-related visual effects.

Sensor Node
Compact electronic or data-themed design.

This is to give it some life rather than a dull page. The idea for nodes are like floating platform in a 3D world. More low poly rather than 4K HDR and raytracing etc.

## Branches

These will also have but some graphics but quite minimal.

- Thin cables
- Data paths
- Glowing lines
- Small moving data points

Again just to make it feel alive.

## Animations

Animation should be subtle.
Possible examples:
- Slow glowing data points travelling along connections
- Gentle node movement
- Small plant movement
- Flowing water
- Soft weather effects
- Light pulsing on active devices
- Smooth zooming between nodes
Animation should add life to the interface without becoming distracting.

## Audio

There is an idea for audio to again feel alive.
Stick to it being subtle noise, this is an application not a concert.
These will also be based on the Nodes Style.

Planter
Light water or leaves.

Weather Station
Soft wind.

System
Subtle electronic ambience.
